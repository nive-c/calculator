# 🖩 Calculator

A sleek, dark-themed calculator web app built with HTML, CSS, and JavaScript.

## ✨ Features
- Basic arithmetic operations — add, subtract, multiply, divide
- Delete last character or clear entire input
- Keyboard support (type numbers and operators directly)
- Smooth hover animations on buttons

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## 🚀 How to Run
Just open `index.html` in your browser. No installation needed.

## 💼 What This Shows
- DOM manipulation with JavaScript
- CSS Grid layout
- Event handling (click + keyboard)
- Clean UI design with dark theme
